# Как получить APK через GitHub Actions

1. Создай новый репозиторий на https://github.com/new (например, `petal-mobile`).
2. Распакуй этот ZIP на компьютере.
3. Загрузи **содержимое** папки `Petal-Mobile-Android` в корень репозитория. В корне должны быть `settings.gradle.kts`, `build.gradle.kts`, папка `app` и папка `.github`.
   - Важно: включи скрытую папку `.github` при загрузке. В ней лежит workflow `workflows/android.yml`.
4. Нажми **Commit changes**.
5. Открой вкладку **Actions** в репозитории. Запустится задача **Build Petal Android APK**.
6. Открой завершившийся запуск (зелёная галочка), найди внизу раздел **Artifacts** и скачай `Petal-Android-APK`.
7. На телефоне скачай ZIP-артефакт, распакуй его и нажми `app-debug.apk`. Разреши установку приложения из этого источника, если Android спросит.

Если сборка упадёт: открой запуск Actions, скопируй красный блок ошибки и пришли его сюда — разберём.

## Важно
- Каждый push в `main` или `master` запускает новую сборку. Также можно запустить вручную через Actions → Build Petal Android APK → Run workflow.
- GitHub хранит APK-артефакт 14 дней.
- Это debug APK для личной установки и тестирования, не подписанный релиз для Google Play.
