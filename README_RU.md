# Petal Mobile для Android

Это первый перенос Petal 1.2.0 на Android на основе исходников из архива `Petal-1.2.0.zip`.

## Что уже реализовано
- Тёмная палитра Petal (фон #13131A, панели #111117, розово-фиолетовые акценты).
- Браузер на Android WebView: адресная строка, поиск, назад, обновить, домашняя страница.
- Несколько вкладок: создание, переключение и закрытие.
- История посещений (в рамках текущего сеанса; сохранение списка).
- Инструменты: простой калькулятор, случайные числа, колесо удачи.
- Меню настроек и загрузок-заглушки.

## Что пока не перенесено
Саундпад с выводом в микрофон, менеджер паролей и шифрованное хранилище, полноценные загрузки, восстановление вкладок, расширения и синхронизация. Это требует отдельной Android-реализации и тестирования.

## Сборка APK
1. Установите Android Studio (Hedgehog или новее) и Android SDK Platform 35.
2. Откройте папку `Petal-Mobile-Android` в Android Studio.
3. Дождитесь Gradle Sync.
4. Выберите Build → Build Bundle(s) / APK(s) → Build APK(s).
5. APK появится в `app/build/outputs/apk/debug/app-debug.apk`.

Требуется интернет-доступ. Минимальная версия Android — 7.0 (API 24).


## Сборка APK на GitHub без Android Studio
В проект уже добавлен workflow `.github/workflows/android.yml`.
Следуй инструкции в `GITHUB_BUILD_RU.md`: загрузи содержимое папки в GitHub-репозиторий, затем скачай APK из раздела Artifacts во вкладке Actions.
